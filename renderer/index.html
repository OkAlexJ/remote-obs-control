Not connected to OBS

Enter the address of the PC running OBS above and press Connect.

  1. In OBS on that PC: Tools → WebSocket Server Settings → tick Enable WebSocket server.
  2. Use its IP (a Tailscale 100.x.x.x address works great across networks) and port (default 4455).
  3. Click Show Connect Info in that window to see the password.

Your soundboard and macros below can be set up while offline.
